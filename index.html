Concepte Fundamentale

Conceptul de Enhanced HTML utilizează tehnologii web (HTML5, CSS3, JS) pentru a transforma o prezentare clasică cu text și imagini într-o experiență captivantă datorită resurselor multimedia (fișiere audio-video, chestionare interactive, jocuri educaționale, diagrame dinamice), designului adaptabil pe orice tip de dispozitiv, și adaptării conținutului la nevoile elevilor cu deficiențe de vedere!.
Spre deosebire de un fișier PDF, formatul Enhanced HTML poate crește implicarea elevilor prin fișiere multimedia! 💡 Acesta este un Pop-up Pedagogic! Oferă elevului definiția instant, fără a-l face să caute la sfârșitul manualului.
